# PhonePe Pulse Data Analytics Project

## Project Overview

This project analyses PhonePe Pulse data from 2018 to 2022 to explore digital payment trends, transaction performance, user distribution, and regional patterns across India.

The project combines data preparation, SQL analysis, Excel-based data auditing, and interactive Power BI visualisation.

## Tools and Technologies

- Python – Data preparation and cleaning
- SQL – Data querying and analysis
- Microsoft Excel – Data quality checks, summaries, and reconciliation
- Microsoft Power BI – Interactive dashboard development

## Project Structure

- `01_PowerBI_Dashboard` – Power BI report and exported dashboard PDF
- `02_Datasets` – Cleaned CSV datasets
- `03_Python` – Python data preparation script
- `04_SQL` – SQL analysis queries
- `05_Excel_Analysis` – Data audit and analysis workbook
- `06_Documentation` – Project documentation and dashboard screenshots
- `07_Presentation` – Final project presentation

## Dashboard Overview

The Power BI dashboard contains three pages:

1. Overall Transaction Performance
2. User and Device Analytics
3. Regional and District Analysis

## Data Scope and Limitations

- The datasets cover the period from 2018 to 2022, subject to the availability of records in each dataset.
- The aggregated user dataset contains records only up to 2022 Q1.
- Registered user figures represent quarterly snapshots and should not be interpreted as unique users across multiple quarters.
- Transaction amounts are reported using the supplied source values because the currency unit is not explicitly specified in the supplied data.

## Project Outcome

The project demonstrates an end-to-end data analytics workflow involving data preparation, validation, querying, analysis, and interactive dashboard development.
